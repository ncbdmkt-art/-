# -政植涯品牌成效記錄板
上傳各社群的所有原始指標(google sheet excel下載成csv檔案，轉成具有 BOM 的 UTF-8編碼。
運用於各種資料的分析數據，提供品牌社群專屬建議。

## 📌 儀錶板能幫你做的事
這是一個追蹤社群品牌成長數據的策略儀表板。
涵蓋四個分頁讓所有數據成為可以被合理詮釋、並提供最小成本做出關鍵決策的基礎架構。

## 📊 四大分頁
策略監測室:提供品牌各渠道與KPI訂定的指標達成率，提供策略修改預測以及總覽各大社群亮眼表現，並最直觀的看見成長。
發布達標沒:提供品牌各渠道細緻分析，包含每日發布的內容是否達成KPI標準、以及分類別的內容影響力矩陣。
活動轉換漏斗:以活動部各類別活動專案宣傳為主，看看哪些貼文和活動需要被額外推廣，來加強轉換率。
客群分析後台:以回饋表單為基準，分析參與活動的客群分布、場次複購率、參與理由以及未來可能的講座主題方向。

## 🚀 目標
追蹤關鍵指標達成率
發現社群策略的亮點與挑戰
讓品牌社群能持續成長!
